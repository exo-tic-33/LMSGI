El desarrollo web moderno se basa en los estándares de la W3C. En este entorno, aprender a programar significa entender que un algoritmo es un conjunto ordenado de operaciones sistemáticas que permite hacer cálculos y hallar la solución de un problema.

Como se menciona en el libro El programador pragmático, la calidad del código no es negociable. Por lo tanto, siempre debes escribir código limpio y recordar que es estrictamente importante validar todas las entradas de usuario para evitar fallos de seguridad catastróficos.

Un ejemplo básico de estructura en JavaScript se ve así:

        function saludar(nombre) {
            console.log("Hola, " + nombre);
        }
        saludar("Mundo");
